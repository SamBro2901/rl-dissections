### C3 — Definition of "return" in the data. VERIFIED

- **`training_metrics.json` structure** (key sets read from every seed-331 run, i.e. one run per algo/env/config; the row keys of `episodes` are identical for all four algorithms): top-level keys `episodes`, `epochs` (nothing else).
